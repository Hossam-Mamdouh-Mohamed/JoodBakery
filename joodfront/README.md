Jood Bakeries - Static Bootstrap RTL

Run locally

- افتح `index.html` مباشرة في المتصفح، أو شغّل خادم محلي:

```bash
python -m http.server 8000
```

أماكن استبدال الصور

- الشعار: `assets/img/logo.png`
- صورة الهيرو: `assets/img/hero.jpg`
- تبويبات الأقسام: `assets/img/cat-*.jpg`
- منتجات مميزة: `assets/img/p1.jpg` … `p6.jpg`

يمكن تعديل النصوص والألوان في `index.html` و`assets/css/styles.css`.
